# iSee 설치 파일

윈도우·맥용 빠른 사진 뷰어 & 사진 정리기 **iSee**의 설치 파일과 자동 업데이트 정보를 올리는 곳입니다. (코드는 비공개)

**최신 버전 받기: [Releases](https://github.com/janghwansangai/isee-releases/releases/latest)**

- **맥** (애플 실리콘·인텔): `iSee_…_universal.dmg`를 열고 iSee를 응용 프로그램 폴더로 끌어 놓습니다. 처음 한 번은 Finder에서 iSee를 **우클릭 › 열기**로 엽니다 (서명하지 않은 앱).
- **윈도우** 10·11: `iSee_…_x64-setup.exe`를 실행합니다. SmartScreen 경고가 뜨면 **추가 정보 › 실행**을 누릅니다.
- 설치한 뒤에는 새 버전이 나오면 앱이 알려 주고 바로 업데이트합니다.
